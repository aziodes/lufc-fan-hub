Easiest sections to make live next
EASY
Player Stats Table — football-data.org doesn't provide per-player stats on the free tier. Could use an iframe embed from FBref.com or upgrade to the paid tier (£20/mo).
EASY
Ticker — already has Google News RSS wired up for the news section. Could pull the top 5 headlines into the ticker from the same feed with no extra API calls.
MEDIUM
Gallery — real match photos require a licensed image API (Getty, PA Media) or scraping the official club media page. Not trivially free.
HARD
Fan Forum / Poll — needs a backend (database + auth). Would require moving beyond a single HTML file to something like Supabase or Firebase.
